# 四柱推命鑑定サイト

Next.js（App Router）+ microCMS で作られた、スマートフォン向けの鑑定サイトです。ダーク×ゴールドの落ち着いたトーンで、占い・スピリチュアル系ブランドに合う今どきの見た目にしています。

- 開発者（あなた）がソースコードを管理します
- かりんさんは microCMS の管理画面から「お知らせ・ブログ」「写真ギャラリー」「鑑定メニュー・料金」「プロフィール」を投稿・編集できます
- 投稿すると、コードを触らずに自動でサイトに反映されます（ISR + Webhook）
- お問い合わせ・ご予約フォームも設置済み（Web3Formsという無料サービス経由でメール受信、月250件まで無料）
- 一般の閲覧者は記事や写真を見るだけで、編集はできません（編集画面はmicroCMS側にあり、サイト上には存在しません）

### ページ構成

| ページ | 内容 | データの出どころ |
|---|---|---|
| `/` ホーム | キャッチコピー・鑑定メニュー抜粋・お知らせ抜粋・ギャラリー抜粋 | menu / news / gallery / profile |
| `/menu` | 鑑定メニュー・料金一覧 | menu |
| `/profile` | かりんさんのプロフィール・SNSリンク | profile |
| `/news` | お知らせ・ブログ一覧 | news |
| `/news/[id]` | お知らせ・ブログ詳細 | news |
| `/gallery` | 写真ギャラリー（ホームからリンク、下部タブには含めていません） | gallery |
| `/contact` | お問い合わせ・ご予約フォーム | Web3Forms |

## 1. まず microCMS 側を準備する

### 1-1. サービスを作成

1. https://microcms.io/ で無料アカウントを作成
2. 「サービスを作成」→ サービスID（例: `karin`）を決める
   - このサービスIDが後で環境変数 `MICROCMS_SERVICE_DOMAIN` になります

### 1-2. APIを4つ作成する

**① 鑑定メニュー・料金 用のAPI**

- **エンドポイント名: `menu`**（必ずこの名前）
- 型: リスト形式
- フィールド:

| フィールドID | 表示名 | 種類 | 必須 |
|---|---|---|---|
| `title` | メニュー名 | テキストフィールド | ○ |
| `price` | 料金 | テキストフィールド（例: `¥8,000（税込）`） | ○ |
| `duration` | 所要時間 | テキストフィールド（例: `約60分`） | - |
| `description` | 説明 | テキストエリア | - |
| `order` | 表示順 | 数値（小さい順に表示されます） | - |

> 参考として、四柱推命鑑定（対面）／オンライン相談／神社参拝ツアー／講座／霊的カルテ鑑定 のようなメニューを想定しています。実際の項目はかりんさんが自由に追加できます。

**② プロフィール 用のAPI**

- **エンドポイント名: `profile`**（必ずこの名前）
- **型: シングル形式**（この1種類のAPIは「リスト形式」ではなく「シングル形式」を選んでください）
- フィールド:

| フィールドID | 表示名 | 種類 | 必須 |
|---|---|---|---|
| `name` | お名前 | テキストフィールド | ○ |
| `catchCopy` | キャッチコピー | テキストフィールド（例: `四柱推命鑑定士`） | - |
| `photo` | 写真 | 画像 | - |
| `bio` | 自己紹介・経歴 | リッチエディタ | ○ |
| `instagramUrl` | InstagramのURL | テキストフィールド | - |
| `lineUrl` | 公式LINEのURL | テキストフィールド | - |

**③ お知らせ・ブログ用のAPI**

- **エンドポイント名: `news`**（必ずこの名前）
- 型: リスト形式
- フィールド:

| フィールドID | 表示名 | 種類 | 必須 |
|---|---|---|---|
| `title` | タイトル | テキストフィールド | ○ |
| `content` | 本文 | リッチエディタ | ○ |
| `eyecatch` | アイキャッチ画像 | 画像 | - |
| `category` | カテゴリ | セレクトフィールド（選択肢: `お知らせ` / `ブログ` / `イベント`） | - |

**④ 写真ギャラリー用のAPI**

- **エンドポイント名: `gallery`**（必ずこの名前）
- 型: リスト形式
- フィールド:

| フィールドID | 表示名 | 種類 | 必須 |
|---|---|---|---|
| `title` | タイトル | テキストフィールド | ○ |
| `image` | 写真 | 画像 | ○ |
| `description` | 説明 | テキストエリア | - |
| `takenAt` | 撮影日 | 日付 | - |

> フィールドを増やしたくなった場合は、`src/types/microcms.ts` の型定義と、表示側のコード（`src/app` 配下）も合わせて修正してください。

### 1-3. APIキーを発行

「サービス設定」→「APIキー」から、GET権限のあるAPIキーを発行し、控えておきます。
（環境変数 `MICROCMS_API_KEY` になります）

### 1-4. かりんさん用のログインアカウントを作成

「サービス設定」→「メンバー」からメールアドレスを招待します。
権限は「編集者」など、コンテンツの作成・編集ができる権限を付与してください（サービス設定自体はいじれない権限にしておくと安全です）。

### 1-5. プロフィールを1件だけ作成しておく

`profile` はシングル形式なので、公開前に一度だけ内容を入力して「公開」しておいてください（未公開だとサイト側に「準備中」と表示されます）。

## 2. お問い合わせフォームの送信先を用意する（Web3Forms）

サーバーやメールの設定なしで、無料でフォーム送信をメール通知できる仕組みです（無料枠: 月250件まで）。

1. https://web3forms.com/ にアクセスし、受信したいメールアドレスを入力して「Create Access Key」
2. 届いたメールのリンクからアクセスキーを有効化し、キーをコピー
3. これが環境変数 `NEXT_PUBLIC_WEB3FORMS_ACCESS_KEY` になります

---

## 3. コードを手元で動かす

```bash
npm install
cp .env.local.example .env.local
```

`.env.local` を開き、以下を実際の値に書き換えます。

```
MICROCMS_SERVICE_DOMAIN=（1-1で決めたサービスID）
MICROCMS_API_KEY=（1-3で発行したAPIキー）
REVALIDATE_SECRET=（好きなランダム文字列。他人に推測されないもの）
NEXT_PUBLIC_WEB3FORMS_ACCESS_KEY=（2で発行したアクセスキー）
```

起動:

```bash
npm run dev
```

http://localhost:3000 をスマートフォンの画面サイズ（開発者ツールでデバイス表示に切り替えると見やすいです）で確認してください。

## 4. Vercelにデプロイする（無料）

1. このプロジェクトをGitHubリポジトリにpush
2. https://vercel.com/ でGitHubアカウント連携してインポート
3. 環境変数（`MICROCMS_SERVICE_DOMAIN` / `MICROCMS_API_KEY` / `REVALIDATE_SECRET` / `NEXT_PUBLIC_WEB3FORMS_ACCESS_KEY`）をVercelのプロジェクト設定 → Environment Variables に追加
4. デプロイすると `https://プロジェクト名.vercel.app` のようなURLが発行されます

> 個人・非商用利用であればVercelの無料Hobbyプランの範囲内で運用できますが、鑑定業として収益が発生する事業サイトの場合はVercelの利用規約上Proプラン(有料)が必要になるケースがあります。利用規約は運用開始前にご確認ください。

## 5. 自動反映（Webhook）を設定する

投稿してから最大60秒ほどで自動的に反映される仕組み（ISR）が既に組み込まれていますが、
「保存した瞬間に反映したい」場合は、microCMS側でWebhookを設定します。

1. microCMSの対象APIの管理画面 →「API設定」→「Webhook」
2. 以下のURLを登録:
   ```
   https://あなたのVercelのURL/api/revalidate?secret=REVALIDATE_SECRETに設定した値
   ```
3. トリガーは「コンテンツ公開時」「コンテンツ更新時」「コンテンツ削除時」すべてにチェック
4. `menu` / `profile` / `news` / `gallery` の4つのAPIすべてに同じ設定をします

これで、かりんさんが投稿を保存した瞬間にサイトへ反映されるようになります。

---

## 6. かりんさん向けの使い方（メモとして渡す用）

1. microCMSの管理画面URL（`https://サービスID.microcms.io` の管理画面）にログイン
2. 更新したいAPI（お知らせ／ギャラリー／メニュー／プロフィール）を選んで「追加」または既存コンテンツを選択
3. 内容を入力
4. 右上の「公開」ボタンを押す
5. 数十秒待ってからホームページを開くと反映されています

お問い合わせフォームからの連絡は、Web3Forms登録時のメールアドレス宛に直接届きます。

## 7. ディレクトリ構成

```
src/
  app/
    layout.tsx           共通レイアウト（ヘッダー・下部タブナビ）
    page.tsx             ホーム画面
    menu/page.tsx          鑑定メニュー・料金
    profile/page.tsx       プロフィール
    news/page.tsx          お知らせ一覧
    news/[id]/page.tsx      お知らせ詳細
    gallery/page.tsx       ギャラリー一覧
    contact/page.tsx       お問い合わせ・ご予約フォーム
    api/revalidate/route.ts  Webhook受け口（自動反映用）
  components/            UIパーツ（ヘッダー・下部ナビ・カード・フォーム等）
  lib/microcms.ts         microCMSからデータ取得する処理
  lib/format.ts           日付表示のフォーマット処理
  types/microcms.ts        microCMSのデータ構造に対応する型定義
```

## 8. デザインについて

`src/app/globals.css` にダーク×ゴールドの配色（CSS変数）をまとめています。色味を変えたい場合は `:root` 内の `--color-*` を変更するだけで全体に反映されます。
